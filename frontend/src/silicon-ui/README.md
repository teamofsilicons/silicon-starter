# Silicon UI in Starter

Foundation tokens and Button/Input CSS come directly from [Silicon UI](https://ui.teamofsilicons.com), copied from the `teamofsilicons/silicon-ui` repository at `7e7bf7aff8d093c5fd14473698c1355d1218f526`. The card base surface is copied from `registry/components/card/card.module.css`.

`../silicon-ui.tsx` adapts native controls to Solid while retaining button and form semantics, keyboard focus, disabled states, and reduced-motion behavior. React-specific label morphs and card quick-look are unused. Product layout lives in the app styles and uses the shared foundation tokens. The MIT notice is served at `/licenses/Silicon-UI.txt`.
